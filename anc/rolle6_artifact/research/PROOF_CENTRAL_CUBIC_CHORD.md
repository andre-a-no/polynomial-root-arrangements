# Хорды и средний корень P‴

В канонической ориентации пусть z₁<z₂<z₃<z₄ — корни P″, c — средний
корень P‴, μ — общее среднее корней, v₋ — левый корень P⁽⁴⁾.
Невозможны условия

    P(z₁)>0, P(z₂)<0, P(c)>0,
    P″(v₋)<0, P″(μ)<0.                                  (1)

Этот запрет даёт четыре новых слова. Знак P(z₃) не требуется в формулировке:
его положительность следует из выпуклости.

## Ограничиваем область без ограничения диапазона поиска

Используем прежнюю нормировку z₂=0,z₃=1:

    P″=(x+u)x(x−1)(x−T), T=1+u+2r, u>0,r>0,
    H=u²+u+2ur−2r−1,
    F=x⁶/30−(1+r)x⁵/10−Hx⁴/12+uTx³/6,
    P=F+Bx+C.

Два последних условия (1) означают H>0 и r>1. Следовательно u>3/5.
По чередованию 0<c<1. Поскольку P″>0 на (0,1), P строго выпукла там.
Из P(0)<0<P(c) следует P(1)>0. Поэтому

    F(−u)/u+F(1)>0.

Из уже проверенного тождества PROOF_MIDDLE_TRIPLE.md эта сумма равна
−(u+1)K/60, где

    K=4ru³+6ru²−6ru−4r+3u⁴+6u³−u²−4u−1.

Значит K<0. Но

    K(u,r)−K(u,1)=2(r−1)(u−1)(2u+1)(u+2),
    K(u,1)=3u⁴+10u³+5u²−10u−5.

Все коэффициенты K(1+U,1) положительны. При r>1,u≥1 получили бы K>0.
Следовательно **3/5<u<1**.

Так как (P″)'(1/2)=r/2>0, средний корень c больше 1/2. Уравнение
(P″)'(c)=0 записывается как

    D=u−2(u−1)c−3c²,
    N=(2c−1)(u²+u+2c−2c²),
    2rD=N.

При 1/2<c<1 имеем N>0, следовательно D>0. Функция D убывает по c
при u>3/5,c≥1/2, а D(u,3/5)=3/25−u/5<0. Значит c<3/5.
Вся допустимая область находится в рациональном прямоугольнике

    3/5<u<1, 1/2<c<3/5.                                 (2)

Исходный параметр r может быть неограниченным; он полностью учтён заменой
r=N/(2D), в том числе при D→0.

## Второе сравнение хорд

Из P(−u)>0, P(0)<0 и P(c)>0 получаем

    E=F(−u)/u+F(c)/c>0.

После подстановки r=N/(2D) выполняется тождество

    E=(u+c)G(u,c)/(60D),

где

    G=6c⁶+10c⁵u−16c⁵−c⁴u²−31c⁴u+9c⁴
      +c³u³+4c³u²+18c³u+7c²u⁴+16c²u³−3c²u²
      +2cu⁵−cu⁴−12cu³−u⁵−2u⁴.

Таким образом, G>0. Обозначим Hₙ=DH после подстановки:

    Hₙ=−4c³u+4c³−3c²u²+3c²u−3c²+u².

Необходимы одновременно

    N−2D>0, Hₙ>0, G>0.                                  (3)

Первое условие — r>1, второе — H>0.

## Пять точных прямоугольников

На замыкании (2) построено покрытие пятью рациональными прямоугольниками.
На одном из них 2D−N≥0, на двух −Hₙ≥0, на двух −G≥0. В каждом случае
нарушается одно из строгих необходимых условий (3).

Коэффициенты Бернштейна проверены точной рациональной арифметикой,
причём каждый конечный прямоугольник дополнительно проверен независимой
прямой формулой. Тождества для D,N,Hₙ,G также проверяются без SymPy.
