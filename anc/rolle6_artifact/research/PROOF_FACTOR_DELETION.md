# Удаление линейного множителя

## Алгебраическая связь

Пусть p=(x-r)g, где r — любой один из шести простых вещественных корней p.
Тогда g имеет степень 5 и пять остальных корней p. Для k>=1

    p^(k)=(x-r)g^(k)+k*g^(k-1).

Если среднее корней p равно нулю, среднее корней g равно -r/5.
Это не отдельная гипотеза: сумма оставшихся пяти корней равна -r.
Равенство средних во всей цепочке производных g включается в систему.

## Чередование и сужение интервалов

Для j=1,...,4 корни g^(j) строго чередуются с корнями p^(j).
Действительно, в каждом корне t_i многочлена g^(j) имеем

    p^(j)(t_i)=j*g^(j-1)(t_i).

Знаки справа — чередующиеся знаки значений строго гиперболического
многочлена в его критических точках. Они дают по одному корню p^(j)
между соседними t_i и по одному снаружи; число полученных корней
совпадает со степенью p^(j). Общих корней нет, поскольку g^(j-1)
и g^(j) общих корней не имеют.

Итак, i-й корень g^(j) лежит строго между i-м и (i+1)-м корнями p^(j).
Для j=0 координаты корней g известны точно: это пять оставшихся корней p.
Интервалы уточняются последовательно по j при помощи тождества

    g^(j)(x)=[p^(j)(x)-j*g^(j-1)(x)]/(x-r),  x!=r.

В каждом исходном узле x знак p^(j)(x) известен. Знак g^(j-1)(x)
известен, если уже полученные интервалы определяют положение всех его
корней относительно x; для фиксированного корня g значение равно нулю.
Если знак числителя определяется без возможной компенсации слагаемых,
известен знак g^(j)(x). Он сужает соответствующий интервал по чётности
числа корней справа. В точке x=r деление не применяется: используется

    g^(j)(r)=p^(j+1)(r)/(j+1).

Все эти знаки ненулевые при исходном условии о 21 различных узлах.
Алгоритм `deletion_bounds` использует только перечисленные операции.

## Точный сертификат

Вводятся 20 исходных положительных промежутков и 10 координат корней
производных g',g'',g''',g^(4). Корни g выражены через исходные промежутки.
Равенства — общие средние корней каждой из двух цепочек. Неравенства —
исходные положительные формы, интервалы выше, чередование, а также
неравенства для критических точек и частичных сумм из BOUND_PROOF.md,
применённые к g и его производным.

Целочисленный сертификат задаёт тождество

    sum(y_i E_i)=sum(z_i B_i),   z_i>=0,   sum(z_i)>0.

При реализации слова слева стоит 0, справа — строго положительное число.
Для запрета достаточно хотя бы одного выбора удаляемого корня r.
Проверка этих сертификатов не использует вещественные приближения.

## Полный перебор типов оставшейся квинтики

Два из найденных запретов сертифицируются уже перечисленными общими
линейными условиями. Для остальных 42 используется опубликованная
полнота 116 реализуемых слов степени 5 (тот же результат Костова,
на котором основана первоначальная верхняя граница).

Можно считать совместное расположение корней g и его производных
невырожденным. Действительно, исходное слово p задаёт открытое множество
в координатах шести простых корней. Зафиксировав удаляемый корень r,
можно независимо мало возмущать остальные пять корней, сохраняя исходное
слово p. Вырожденные расположения g принадлежат конечному объединению
собственных алгебраических множеств: равенство двух корней разных
производных задаётся соответствующим результантом. Их дополнение плотно.
Следовательно, существование p с данным словом влечёт существование
такого p с тем же словом и с одним из 116 невырожденных типов g.

Для КАЖДОГО из 116 типов в систему добавлены 14 строгих линейных
неравенств, задающих полный порядок 15 корней g,g',...,g^(4).
Для каждого типа отдельно сохранён целочисленный сертификат противоречия.
Проверяющий код требует точного совпадения множества рассмотренных типов
с полным списком степени 5, а затем проверяет все тождества.
Таким образом, численное отсутствие решения не используется как
доказательство ни для одного случая.

Этот этап проверил все шесть удалений для 2516 слов, оставшихся после
полярного этапа, и исключил ещё 44. Для остальных 2472 получена лишь
совместимость проверенных линейных необходимых условий; существование
самого многочлена этим не доказано.

## Удаление двух корней

Аналогично p=(x²+a*x+b)h, где a=-(r+s), b=r*s и r!=s — корни p.
Поэтому a²-4b=(r-s)²>0. По формуле Лейбница

    p^(k)=(x²+a*x+b)h^(k)+k*(2x+a)h^(k-1)+k*(k-1)h^(k-2),

с отсутствующими членами при k<1 или k<2. Среднее корней h равно
-(r+s)/4 при исходном среднем p, равном нулю.
На данном этапе удаления одного корня отдельный поиск по квадратичному
множителю не выполнялся. Последующее исследование двух согласованных
удалений и его восемь дополнительных запретов описаны отдельно:
PROOF_JOINT_DELETION.md.

Эти разложения не являются взаимоисключающими случаями: каждый
рассматриваемый p допускает все шесть удалений одного корня и все
пятнадцать удалений пары. Следует требовать совместимости каждого
выбранного удаления, а при подсчёте брать объединение исключений.
Публикационная новизна формулы Лейбница и общих свойств чередования
не заявляется.
