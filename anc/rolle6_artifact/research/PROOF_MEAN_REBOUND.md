# Четыре исключения одним сертификатом: возврат к положительному значению

Этот цикл исключает сразу четыре слова:

    010213204132015043210
    010213204132051043210
    012340150231402312010
    012340510231402312010.

Они образуют две пары отражения. После получения этого единого сертификата
дальнейший поиск остановлен. Постановка прежняя: шесть простых вещественных
корней P; все 21 корень P,P',...,P^(5) попарно различны; отражения считаются
отдельно. Число связных компонент пространства коэффициентов не вычисляется.

## 1. Общая геометрия четырёх слов

В выбранной ориентации и аффинной нормировке

    R=P''=(x+u)x(x-1)(x-T), T=1+u+2r, u,r>0,
    H=u²+u+2ur-2r-1, mu=(1+r)/2,
    P=F+Bx+C,
    F=x⁶/30-(1+r)x⁵/10-Hx⁴/12+uTx³/6, Q=F'.

Корень P^(5) находится в mu. Пусть v_- — левый корень R''.
Позиции символов в словах дают

    R(v_-)>0, R(mu)<0, P(0)>0, P(1)<0, P(mu)>0.

По чередованию корней и формуле для mu первые два условия означают H<0,r>1.
Тогда mu>1. Из H<0 следует u<1: H возрастает по u и H(1,r)=1.

Из C=P(0)>0 и P(1)<0 следует B<-F(1). При шести простых вещественных
корнях P производная P' имеет пять простых вещественных корней; её первый
локальный максимум при x=-u положителен. Следовательно Q(-u)+B>0 и

    C0=60[Q(-u)-F(1)]>0.

Кроме того

    P(mu)-mu P(1)=F(mu)-mu F(1)-(mu-1)C>0,

поэтому

    S=960[F(mu)-mu F(1)]/[mu(mu-1)]>0.

Здесь C0 — вспомогательный полином, не свободный член C.

## 2. Сведение параметров к компактной области

Полиномы вычисляются точно из F. В частности,

    C0=10ru⁴+20ru³-10ru-4r+8u⁵+20u⁴+10u³-5u²-5u-1,
    S=-2(5r⁴+20r³u+10r³+10r²u²+10r²u-10r²
           -100ru-50r-50u²-50u-11).

Разложим -S по степеням r-3. На 0<=u<=1 коэффициенты имеют точные
нижние границы по Бернштейну

    848, 1400, 700, 140, 10.

Все они положительны, поэтому r>=3 несовместимо с S>0. Значит 1<r<3.
На прямоугольнике 0<=u<=3/5,1<=r<=3 нижняя граница -C0 равна
15031/3125>0. Это несовместимо с C0>0. Получена область

    3/5<u<1, 1<r<3.

## 3. Левая часть графика вынужденно положительна

Пусть x=-(u+z), z>=0. По точному тождеству определим полином G:

    60[F(-(u+z))+(u+z)F(1)]
      =(u+z)(u+z+1)G(u,r,z).

Докажем G>=0 при необходимых H<0,S>0,C0>0.
На прямоугольнике [3/5,1] x [1,3] x [0,2] сертификат из 18 листьев
бинарного покрытия устанавливает неотрицательность одного из полиномов

    H, -S, -C0, G.

Первые три альтернативы противоречат строгим необходимым условиям;
остаётся G>=0. Для z>=2 разложим G по степеням z-2. Пять коэффициентов
на [3/5,1] x [1,3] имеют положительные нижние границы

    126667/625, 37181/125, 3833/25, 154/5, 2.

Таким образом, вся неограниченная область z>=0 покрыта.
Поскольку B<-F(1), C>0 и x<0, получаем

    P(x)>F(x)-xF(1)>=0    при x<=-u.

Но первый критический корень s1 многочлена P лежит левее -u, а при шести
простых вещественных корнях требуется P(s1)<0. Противоречие доказывает
невозможность всех четырёх слов.

## 4. Что проверено программой

`mean_rebound_obstruction.py` использует только стандартную библиотеку Python.
Он независимо восстанавливает из F все полиномиальные тождества, проверяет
сведение параметров, оба неограниченных хвоста и все 18 листьев покрытия.
Коэффициенты Бернштейна вычисляются точной арифметикой Fraction; их минимумы
сверяются двумя разными формулами. Генератор SymPy не нужен для проверки.

Полная проверка этого цикла:

    python3 research/work/cycle_mean_rebound/verify_cycle.py

Также проверены неизменность предшествующих сертификатов по хешам, все 2706
точных примеров, независимое чтение предиката из позиций символов во всех
13404 кандидатах и отсутствие двойного счёта.

Правило отмечает 288 исходных кандидатов. Из них 284 уже исключены раньше;
четыре исключаются впервые относительно сохранённого остатка из 22 слов.
Ни одна из 2706 реализаций не отвергается. Текущие границы:

    2706 <= a6 <= 2724.

Остаются 18 слов. Один сертификат сразу дал четыре исключения, поэтому
порог остановки достигнут. Следующий исследовательский цикл возможен
только после явной команды пользователя продолжить.
