## 2. Нормировка

Старший коэффициент $p$ считаем положительным. Положительная аффинная замена аргумента переводит два корня $p^{(4)}$ в $-1,+1$. Их середина — корень $p^{(5)}$ и общее среднее корней — переходит в нуль. Положительным масштабированием значений добиваемся

$$p^{(4)}(x)=3(x^2-1),\qquad p'''(x)=x^3-3x+b.$$

Невырожденность даёт $b\ne0$: иначе нуль был бы общим корнем $p'''$ и $p^{(5)}$. При необходимости отражаем аргумент и считаем $b>0$. Три простых вещественных корня кубического многочлена требуют $0<b<2$. На $(-1,1)$ он строго убывает, так что его средний корень положителен. Ориентация $b>0$ считывается из слова: средний корень $p'''$ правее корня $p^{(5)}$.

Интегрирование даёт

$$p(x)=\frac{x^6}{120}-\frac{x^4}{8}+\frac{bx^3}{6}+\frac{Ax^2}{2}+Bx+C.$$

Обозначим через $P_-,P_0,P_+$ значения $p$ в $-1,0,+1$; через $Q_-,Q_0,Q_+$ — значения $p'$; через $R_-,R_0,R_+$ — значения $p''$. Тогда

| Значение | Выражение |
|---|---|
| $P_-$ | $C+A/2-B-b/6-7/60$ |
| $P_0$ | $C$ |
| $P_+$ | $C+A/2+B+b/6-7/60$ |
| $Q_-$ | $B-A+b/2+9/20$ |
| $Q_0$ | $B$ |
| $Q_+$ | $B+A+b/2-9/20$ |
| $R_-$ | $A-b-5/4$ |
| $R_0$ | $A$ |
| $R_+$ | $A+b-5/4$ |

Каждый знак определяется словом: для положительного старшего коэффициента знак производной в точке равен $(-1)^m$, где $m$ — число её корней правее этой точки. Никакое из девяти значений не равно нулю.

## 3. Четыре тождества

Подстановка из таблицы даёт точные равенства

$$\tag{I} -3P_- -3Q_- +3P_+ -3Q_+ +2b=0;$$
$$\tag{II} 3P_- +6Q_0 -3P_+ +b=0;$$
$$\tag{III} P_- -2P_0 -R_0 +P_+=-\frac7{30};$$
$$\tag{IV} 3P_- -4R_0 -3P_+ +6Q_+ -2R_+=-\frac15.$$

Следовательно, при $b>0$ невозможны сочетания:

| Тождество | Запрещённые знаки | Новых исключений |
|---|---|---:|
| I | $P_-<0,\ Q_-<0,\ P_+>0,\ Q_+<0$ | 20 |
| II | $P_->0,\ Q_0>0,\ P_+<0$ | 96 |
| III | $P_->0,\ P_0<0,\ R_0<0,\ P_+>0$ | 96 |
| IV | $P_->0,\ R_0<0,\ P_+<0,\ Q_+>0,\ R_+<0$ | 86 |

**Доказательство:** каждое ненулевое слагаемое соответствующей левой части строго положительно, а правая часть неположительна. Приближённые корни и численные допуски в доказательстве не используются.

Последний столбец учитывает только слова, пережившие предыдущие этапы. На этом остатке четыре множества попарно не пересекаются и дают 298 слов. На более широких списках пересечения есть.

Тождество III можно записать без нормировки. Если $u_\pm=\mu\pm h$ — корни $p^{(4)}$, $h>0$, то точная формула Тейлора и равенство $p^{(4)}(\mu)=-p^{(6)}h^2/2$ дают

$$p(u_-)+p(u_+)-2p(\mu)-h^2p''(\mu)
=-\frac7{180}p^{(6)}h^6<0.$$

Это непосредственно запрещает $p(u_\pm)>0$, $p(\mu)<0$, $p''(\mu)<0$.

## 4. Два избыточных правила удалены

Первоначально поиск дал шесть сертификатов. Удалённое тождество

$$3P_-+Q_-+4Q_0-3P_++Q_+=0$$

запрещало $P_->0$, $P_+<0$, $Q_0>0$ при дополнительных $Q_->0,Q_+>0$. Первые три условия уже запрещены II.

Второе удалённое тождество

$$6P_- -6P_0 -7R_0 +6Q_+ -2R_+=-\frac9{10}$$

запрещало $P_->0$, $P_0<0$, $R_0<0$, $Q_+>0$, $R_+<0$. При $P_+>0$ действует III; при $P_+<0$ — IV. Равенство исключено невырожденностью. Значит, этот запрет также покрыт оставшимися.

Избыточность установлена логически, а не только сравнением списков. Исходные шесть сертификатов не являются шестью независимыми методами. Сохранены четыре достаточных правила; их независимость как алгебраических утверждений не заявляется.

Для слов производной `012031201043210` и `012340102130210`, при обоих знаках $p(\mu)$, по-прежнему известны 17 реализуемых слов и остаётся по одному спорному. Новые правила их не исключают.

У первоначальной идеи использовать только знаки в корнях $p''',p^{(4)},p^{(5)}$ есть ограничение. Если все предписанные значения $p$ в этих точках отрицательны, то для любого подходящего представителя производной можно обеспечить это уменьшением свободной константы. Но шесть вещественных корней самого $p$ при этом могут исчезнуть. Для таких случаев нужны дополнительные условия в критических точках $p$ или эквивалентные условия гиперболичности первообразной. Четыре тождества дают необходимые условия, но не полный критерий реализуемости.
