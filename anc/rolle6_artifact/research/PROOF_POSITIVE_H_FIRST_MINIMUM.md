# Ещё шесть исключений: невозможный знак первого минимума

Одним сертификатом исключены три пары отражения:

| Слово | Отражение |
|---|---|
| 010213420310210543210 | 012345012013024312010 |
| 010213420312010543210 | 012345010213024312010 |
| 010213420315240103210 | 012301042513024312010 |

Считаются слова Ролля для шести простых вещественных корней P в общем
положении: все 21 корень P,P',...,P^(5) различны. Отражения различаются.
Число компонент пространства коэффициентов здесь не вычисляется.

## 1. Знаковое препятствие

Используем прежнюю аффинную нормировку, выбрав положительный старший
коэффициент и ориентацию c<mu:

    R=P''=(x+u)x(x-1)(x-T), T=1+u+2r, u,r>0,
    H=u²+u+2ur-2r-1,
    P=F-qx+C, Q=F',
    F=x⁶/30-(1+r)x⁵/10-Hx⁴/12+uTx³/6.

Здесь a<c<d — корни R', v_-<v_+ — корни R'', mu=(1+r)/2 — корень R'''.
Обоснование ориентации: R'(mu)=-r(r+u)(r+u+1), mu лежит между a и d,
а T>1 до отражения гарантирует r>-u/2. Поэтому c<mu равносильно r>0.

Общий предикат шести слов:

    R(v_-)<0, P'(a)<0, P(0)>0.

Первое условие эквивалентно H>0: v_- находится между a и c, v_+>0,
R''(0)=-2H. Второе и третье означают

    q>Q(a), C>0.                                       (1)

Если P имеет шесть простых вещественных корней, то первый корень s1
производной P' лежит левее -u и является минимумом с P(s1)<0. Также

    0<q<min(Q(-u),Q(1)), q=Q(s1).                     (2)

Покажем, что (1),(2),H>0 вынуждают P(s1)>0. Условие r>1 не требуется:
доказательство охватывает всё r>0, включая два режима расположения mu.

## 2. Компактные параметры, включая неограниченный предел

Знаки

    R'(-3u/4)=-u(6ru+16r+3u²+14u+8)/16<0,
    R'(-u/2)=u²(r+u+1)/2>0

дают a=-ut, 1/2<t<3/4. На (-u,0) Q убывает, так что
q>Q(a)>Q(-u/2). Полином 480[Q(-u/2)-Q(1)] после подстановки
u=2+U,r=V имеет только положительные коэффициенты, постоянный равен 1408.
Таким образом, (2) исключает u>=2. H возрастает по u, а
H(3/5,r)=-(20r+1)/25<0, поэтому u>3/5.

Тождество

    Q(-3u/2)=-9u⁴(5r+7u+5)/160<0

и возрастание Q на (-∞,-u) дают s1=-uv, 1<v<3/2.

В точке a логарифмическая производная R равна нулю:

    1/[u(1-t)] - 1/(ut) - 1/(ut+1) - 1/(ut+T)=0.

Отсюда для D=ut(3t-2)+2t-1 имеем

    D=ut(1-t)(ut+1)/(ut+T)>0.

Определим

    N=(2ut+1)[u(1-2t²)-2t+1], DN=2D+N,
    TN=(1+u)D+N, HN=D(u²+u-1)+N(u-1), Hb=HN/u.

Точное решение уравнения R'(-ut)=0 даёт r=N/(2D). Следовательно
N>0, HN=DH, Hb>0. Hb является полиномом: HN делится на u.
Весь необходимый набор параметров содержится в

    B=[3/5,2] x [1/2,3/4] x [1,3/2] по (u,t,v).       (3)

Предел r→∞ соответствует D→0 и не теряется: покрывается весь замкнутый
прямоугольник (3); невозможность используется только при строгих
необходимых ограничениях D>0,N>0,Hb>0.

## 3. Полиномиальная нижняя оценка минимума

Пусть E(x)=60D F(x). Из определений

    E(x)=2Dx⁶-3DNx⁵-5HNx⁴+10uTNx³.

Введём полиномы

    QA=E'(-ut)/u⁴, QX=E'(-uv)/u⁴,
    G=[E(-uv)+uv E'(-ut)]/(u⁵v).

Все деления точные в кольце полиномов. Условия (1),(2) дают
QX>QA и QX>0. Если G>=0, то

    P(s1)=F(-uv)+uv q+C
          > F(-uv)+uv Q(a)=u⁵v G/(60D)>=0,

вопреки P(s1)<0. Таким образом, на каждом блоке достаточно доказать
неотрицательность хотя бы одного из шести полиномов

    -D, -N, -Hb, G, QA-QX, -QX.                       (4)

Кроме G, каждый из них противоречит строгому необходимому ограничению.

## 4. Квадрат у вырожденной границы

Вблизи (u,t,v)=(1,1/sqrt(3),sqrt(5/3)) простая оценка коэффициентов G
заменяется точным тождеством. Положим

    S=(2t/9)(3v²-5)²,
    L=(Hb-D)/(u-1),
    A=[G(1,t,v)-S]/(3t²-1),
    B0=[G-S-D A]/(u-1), E0=L A-B0.

Это полиномы; их коэффициенты содержатся в сертификате под именами L,B,E.
Проверяются тождества

    Hb-D=(u-1)L,
    L(G-S)=D E0+Hb B0.                                (5)

На прямоугольнике

    [99/100,101/100] x [577/1000,578/1000] x [128/100,130/100]

минимальные коэффициенты Бернштейна положительны:

| Полином | Точная нижняя граница |
|---|---|
| L | 595780147/1562500000 |
| B0 | 33755682058566496681631/112500000000000000000000 |
| E0 | 5750298569189481927881/12207031250000000000000 |

Из D>0,Hb>0,L>0 и S>=0 тождество (5) даёт G>=0. Тем самым
вырожденная область проверяется без потери точности на почти нулевых
числах и без исключения какого-либо бесконечного хвоста.

## 5. Сертификат и учёт новых слов

`data/positive_H_first_minimum_certificate.json` содержит покрытие (3)
81 рациональным блоком: 161 узел, глубина не более 27. Из них 33 листа
используют -D, 14 используют -Hb, 26 — G, 6 — QA-QX, 2 — тождество (5).
Каждый обычный лист имеет неотрицательные коэффициенты Бернштейна
выбранного полинома (4). Два специальных листа целиком находятся внутри
области, для которой доказано (5).

`positive_H_first_minimum_obstruction.py` независимо восстанавливает
полиномы из E, проверяет тождества и сведение области, затем проверяет
покрытие точной арифметикой Fraction. Минимумы коэффициентов на каждом
листе и в локальной области сверяются двумя реализациями.

Полная проверка дополнения:

    python3 research/work/cycle_positive_H_first_minimum/verify_cycle.py

Она также проверила хеши прежних доказательств, все 2706 точных примеров
и совпадение предиката с прямым чтением знаков из позиций символов во
всех 13404 исходных кандидатах. Правило отмечает 954 кандидата; 948 были
исключены ранее. Новые относительно сохранённого остатка — ровно шесть
слов, перечисленных в начале. Реализуемых слов среди отмеченных нет.

Текущие границы без двойного счёта:

    2706 <= a6 <= 2712.

Остаются шесть слов. Точное число 2706 пока не утверждается. Один общий
сертификат достиг порога остановки; дальнейший поиск в этом цикле
не проводился. Продолжение — только по явной команде пользователя.
