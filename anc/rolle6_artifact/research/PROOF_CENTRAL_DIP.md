# Последние шесть слов: центральное отрицательное значение

Один сертификат исключает три пары отражения:

| Слово | Отражение |
|---|---|
| 010213204130524103210 | 012301425031402312010 |
| 010213204130524130210 | 012031425031402312010 |
| 010213204130524132010 | 010231425031402312010 |

Постановка прежняя: шесть простых вещественных корней P, все 21 корень
P,P',...,P^(5) попарно различны. Считаются слова Ролля с различением
отражений, а не компоненты пространства коэффициентов.

## 1. Необходимые условия из слова

Нормируем P положительным множителем, а переменную аффинным преобразованием
и отражением, чтобы

    R=P''=(x+u)x(x-1)(x-T), T=1+u+2r, u,r>0,
    H=u²+u+2ur-2r-1,
    P=F-qx+C, Q=F',
    F=x⁶/30-(1+r)x⁵/10-Hx⁴/12+uTx³/6.

Пусть a<c<d — корни R', v_-<v_+ — корни R'', mu=(1+r)/2 — корень R'''.
Ориентация выбрана по c<mu; как и в предыдущих дополнениях, это r>0.
Общий предикат шести слов:

    R(v_-)>0, R(mu)>0, R(v_+)<0,
    P'(a)<0, P(c)<0, P'(v_+)>0, P(0)>0.              (1)

Первые три условия, с учётом чередования корней, дают

    H<0, 0<r<1, v_+>1, H+6r>0.                    (2)

Действительно, v_->0 равносильно H<0 по R''(0)=-2H; c<mu<d и R(mu)>0
означают mu<1. Затем v_-<1<v_+ и R''(1)=-12r-2H<0 дают последнюю оценку.
Из H<0 и H(1,r)=1 следует u<1.

Шесть простых вещественных корней P требуют пяти простых корней P'.
Для первого из них, s1<-u, необходимо P(s1)<0. Имеем

    C>0, 0<q<min(Q(-u),Q(1)), q=Q(s1),
    q>Q(a), q>F(c)/c, q<Q(v_+).                   (3)

Неравенство q>F(c)/c следует из P(c)=F(c)-qc+C<0 и C>0.

## 2. Ограниченная область параметров

Как ранее, R'(-3u/4)<0 и R'(-u/2)>0, поэтому a=-ut, 1/2<t<3/4.
Из Q(-3u/2)=-9u⁴(5r+7u+5)/160<0 и возрастания Q левее -u следует
s1=-uv, 1<v<3/2.

Также c>1/2, поскольку R'(1/2)=r/2>0. На (0,1) Q строго возрастает,
Q(0)=F(0)=0, поэтому F(x)/x строго возрастает. Из (3):

    q>F(c)/c>2F(1/2), q<Q(-u).

На прямоугольнике 0<=u<=2/5, 0<=r<=1 все коэффициенты Бернштейна
полинома 2F(1/2)-Q(-u) положительны, минимум равен 2143/1000000.
Эта область невозможна. Значит 2/5<u<1.

Положим, как в предыдущем дополнении,

    D=ut(3t-2)+2t-1,
    N=(2ut+1)[u(1-2t²)-2t+1], DN=2D+N,
    TN=(1+u)D+N, HN=D(u²+u-1)+N(u-1), Hb=HN/u.

Из логарифмической производной R в точке a:

    D=ut(1-t)(ut+1)/(ut+T)>0, r=N/(2D), HN=DH.

Условия (2) становятся

    D>0, N>0, N<2D, Hb<0, HN+3N>0.               (4)

Вся необходимая область содержится в замкнутом прямоугольнике

    B=[2/5,1] x [1/2,3/4] x [1,3/2] по (u,t,v).   (5)

Его границы не отбрасываются; D>0 требуется только для исходной
физической области, а покрытие проверяется на всём B.

## 3. Полиномы, которые проверяет сертификат

Обозначим E(x)=60D F(x). Тогда

    E(x)=2Dx⁶-3DNx⁵-5HNx⁴+10uTNx³,
    QA=E'(-ut)/u⁴, QX=E'(-uv)/u⁴,
    Gq=[E(-uv)+uv E'(-uv)]/u⁵.

Все эти выражения являются полиномами. Из (3) следуют QX>QA,QX>0.
Из P(s1)=u⁵Gq/(60D)+C<0 и C>0 следует Gq<0.

Первые восемь проверяемых полиномов:

    -D, -N, N-2D, Hb, -(HN+3N), QA-QX, -QX, Gq.   (6)

Неотрицательность любого противоречит строгому необходимому условию.
Два следующих полинома используют рациональные оценки корней на блоке.

### Нижняя граница центрального корня

Выбирается константа 1/2<=c_L<1. Граница c_L=1/2 известна аналитически;
остальные доказываются равномерной оценкой 2D R'(c_L)>=0 на блоке.
Так как a<0<c_L<1<d, это даёт c_L<=c. Следовательно

    q>F(c)/c>=F(c_L)/c_L.

Неотрицательность девятого полинома

    E(c_L)/c_L-E'(-uv)                            (7)

противоречит этому неравенству.

### Нижняя граница правого корня R''

Выбирается константа 1<=w<2. Граница w=1 известна из (2); остальные
доказываются равномерной оценкой -2D R''(w)>=0. Поскольку v_-<1<=w,
получаем w<=v_+. На [1,v_+] Q убывает, поэтому

    q<Q(v_+)<=Q(w).

Неотрицательность десятого полинома

    E'(-uv)-E'(w)                                (8)

даёт противоречие.

Формулы для проверки корневых границ:

    2D R'(x)=8Dx³-6DNx²-4HNx+2uTN,
    2D R''(x)=24Dx²-12DNx-4HN.

## 4. Конечная точная проверка

`data/central_dip_certificate.json` задаёт бинарное разбиение всего B
на 194 рациональных блока: 387 узлов, максимальная глубина 28.

| Проверяемый полином | Число листьев |
|---|---:|
| -D | 0 |
| -N | 3 |
| N-2D | 3 |
| Hb | 5 |
| -(HN+3N) | 3 |
| QA-QX | 63 |
| -QX | 0 |
| Gq | 72 |
| Центральная оценка (7) | 22 |
| Правая оценка (8) | 23 |

Каждый лист проверяется точной рациональной арифметикой Fraction:
все коэффициенты выбранного полинома в тензорном базисе Бернштейна
неотрицательны. Корневые границы на 45 соответствующих листьях
проверяются отдельно на всём блоке. Минимумы коэффициентов сверяются
двумя реализациями; численные приближения корней не используются.
Дерево разбиения проверяется на отсутствие пропусков.

Первая попытка использовала слишком грубую границу c_L и не завершила
покрытие. Её журнал сохранён как неудачная попытка, не как доказательство.
Окончательный сертификат использует (7),(8); неудачи численного поиска
не являются основаниями для исключения слов.

Проверка текущего цикла:

    python3 research/work/cycle_central_dip/verify_cycle.py

Правило отмечает 390 исходных кандидатов. Из них 384 исключены ранее;
ровно шесть составляют весь сохранённый остаток. Известные реализации
не затронуты. Предикат независимо сверен с позициями символов во всех
13404 кандидатах, и все 2706 реализаций повторно проверены.

## 5. Итоговая цепочка подсчёта

Полная воспроизводимая проверка, включая историческую базу и все дополнения:

    python3 research/check_complete.py

Исторический `check_all.py` проверяет базовую границу 2706–2734 и остаётся
неизменным. Семь дополнительных правил затем исключают 28 оставшихся слов
непересекающимися порциями 2,2,2,4,6,6,6. Для каждого проверены сертификат,
отсутствие пересечения с реализациями и точный прирост относительно остатка.
Таким образом, после успешной полной проверки получено

    a6 = 2706.

Это точное число слов в указанной постановке. Утверждений о числе компонент
пространства коэффициентов или о публикационной новизне результат не содержит.
После одного общего сертификата для последних шести слов дальнейший
исследовательский поиск остановлен по правилу пользователя.
