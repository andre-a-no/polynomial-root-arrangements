# Прямое следствие формул квадратуры: ещё два исключения

Используется прежняя нормировка

\[
P(x)=x^6/120-x^4/8+bx^3/6+Ax^2/2+Bx+C,
\qquad Q=P',\qquad S=P'''=x^3-3x+b.
\]

Пусть a<c<d — корни S. Отражением выбираем c<0. Это допустимо:
случай c=0 запрещён условием несовпадения корней всех производных,
поскольку P⁽⁵⁾(0)=0. Имеем a+c+d=0 и b=3c−c³<0.

## Лемма

Невозможна ни одна из следующих совокупностей строгих знаков:

1. P(a)>0>P(d), Q(a)>0, Q(d)>0.
2. P(−1)>0>P(1), Q(−1)>0, Q(1)>0.

Действительно, при h=d−a>0 точное тождество даёт

\[
P(d)-P(a)=\frac h2\bigl(Q(a)+Q(d)\bigr)-\frac{c h^5}{40}>0.
\]

Но P(a)>0>P(d) требует отрицательной разности. Для второй пары
используется аналогичное тождество

\[
P(1)-P(-1)=Q(-1)+Q(1)-\frac{2b}{3}>0.
\]

Оба тождества уже были доказаны в PROOF_LAGUERRE_TRAPEZOID.md;
`laguerre_trapezoid_obstruction.check_identities()` проверяет их точной
рациональной арифметикой. Здесь используется новое для подсчёта следствие
этих же тождеств. Дополнительное неравенство Лагерра не требуется.

## Применение к словам

Канонический порядок шести маркеров — a,−1,c,0,1,d. В каждом маркере
берутся знаки P,P′,P″. Для положительного старшего коэффициента знак
производной вычисляется как (−1) в степени числа её корней справа от
маркера. Поэтому проверка четырёх знаков непосредственно следует из
слова, а не из численного подбора коэффициентов.

Первое правило исключает из прежнего остатка 96 слов ровно

```
012010342531240130210
012031042135243010210
```

Они переходят друг в друга при отражении. Второе правило не добавляет
новых исключений на этом этапе. Применимость обоих правил проверяется
также на всех 2706 известных реализуемых словах и на исходном списке
13404 кандидатов для учёта перекрытий с прежними методами.

После полной проверки счётчика новые границы: 2706≤a₆≤2800;
неизвестных слов 94 (47 пар отражения). Новизна для литературы
не утверждается. Это дополнение к учёту следствий уже известного нам
тождества, а не независимый от него метод.
